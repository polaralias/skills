# Legacy engineering skill archive

This flat directory preserves the final source of engineering packages absorbed by `engineering-workflow`. Archived packages are historical and compatibility evidence, not active skills, routing candidates, install sources, or independently maintained implementations.

The package contents were moved without rewriting their skill source. New engineering behaviour belongs in [`engineering-workflow`](../skills/engineering/engineering-workflow/). `repo-setup` remains active separately because repository bootstrap precedes the material engineering lifecycle.

Legacy names and acronyms remain accepted only through `engineering legacy route <name>`.
