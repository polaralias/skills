# Validation Pass

After editing, check the repaired artefact for these failure modes:

- one contradiction removed but a new one introduced
- output requirements made less coherent by the fix
- voice or operating stance changed more than intended
- linked reference files now out of alignment
- added coverage creating avoidable verbosity
- the rewrite increasing cognitive burden instead of reducing it

If you provide a change summary, keep it compact:

- what changed
- which execution risk it addressed
- whether a further review pass would still be worthwhile
