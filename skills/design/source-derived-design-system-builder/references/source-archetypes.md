# Source archetypes

Use this file to decide what kind of design system is being extracted.

## Brand

Best for:
- marketing websites
- editorial pages
- campaigns
- pitch surfaces
- visual identity systems

Extract:
- logo and mark handling
- display/body typography
- CTA hierarchy
- imagery direction
- section rhythm
- brand tone

## Platform

Best for:
- product UI
- dashboards
- settings/admin/reporting surfaces
- operational tools
- data-heavy workflows

Extract:
- shell structure
- navigation
- tokens
- density
- states
- component patterns
- interaction rules

## Variant

Best for:
- a themed product variant
- a learning hub
- a docs/help centre
- a catalogue environment
- a community/content workspace

Extract:
- inherited shell
- changed identity layer
- content structure
- category system
- instructional or tonal shifts
- differences from the parent system

## Rule

If multiple archetypes are present, separate them rather than averaging them together.
