# Extraction checklist

Use this checklist when turning source material into `SKILL.md` plus `DESIGN.md`.

## Source audit

- What is the primary source?
- What is authoritative vs exploratory?
- What is static vs likely outdated?
- What parts of the system are actually covered?

## Stable tokens

- colours
- typefaces
- font roles
- spacing
- radius
- shadows/elevation
- core component values

## Behavioural rules

- how hierarchy works
- where density should sit
- when asymmetry matters
- how navigation behaves
- how copy should sound
- what interaction states are expected

## Boundary questions

- is this brand, platform, or variant?
- what should this system not be used for?
- what sibling systems exist?
- what needs live inspection before production use?

## Final package check

- does `SKILL.md` teach usage clearly?
- does `DESIGN.md` capture stable tokens clearly?
- are extrapolated areas called out?
- could another agent reuse this without reprocessing the raw source pack?
