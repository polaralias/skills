# ElevenLabs Reference Outputs

These example outputs are the benchmark for tag restraint, tone shifts, and spoken-language cleanup.

## 1. Post-first discussions

[thoughtful] "Discussions are strongest when people bring their own thinking before they react to everyone else. This feature is built to support exactly that. [excited] Let’s look at how it works."

[informative] "When an author is setting up a discussion, there is now a content-rule toggle called 'Require response before viewing others'. It can be turned on or off for each discussion, which means you can use it where independent thinking matters most."

"When that setting is enabled, participants see a clear message telling them they need to post their own response before other replies become visible. The message also tells them how many responses are waiting to be unlocked, which adds a gentle sense of momentum."

"If someone is the first person to join the discussion, they see a different message inviting them to go first. After posting, only their own response is visible until someone else joins in. [thoughtful] It is a subtle but useful way to acknowledge that they are setting the tone."

"As soon as a participant submits their response, the discussion opens up and the rest of the responses become visible. From there, they can read, reply, and engage with the wider conversation, but only after contributing their own view first."

[happy] "That is post-first discussions: a simple way to encourage original thinking before peer influence takes over. Use it where independent responses matter, and let the conversation deepen afterwards."

## 2. Forms with privacy and reporting controls

[thoughtful] "Forms are often where people share the most sensitive information, so privacy and reporting controls matter. These updates make that much easier to manage."

[informative] "Authors can now configure forms with more control over how information is collected and stored. One of the most important additions is privacy-first submission. When that is enabled, user IDs are replaced with one-way hashed values, which means reports no longer expose a direct link back to an individual."

[reassuring] "People filling out the form also see a clear consent message explaining that their responses will be stored securely and anonymously. That makes the process feel safer and more transparent."

[thoughtful] "Authors can also define minimum submission and answer thresholds before data appears in reporting. That helps prevent low-volume responses from becoming identifiable. The privacy protection is not an afterthought. It is built into the reporting model itself."

[confident] "Taken together, these controls make forms far better suited to sensitive use cases. You still get usable aggregate insight, but with much stronger protection for the people responding."

## 3. Profile review configuration

[thoughtful] "Personalisation only works well when the information behind it stays accurate. This feature helps keep that profile data current."

[informative] "Administrators now have a dedicated profile-review setup screen where they can define when reviews happen, how often they repeat, and what message people see when they are asked to update their information."

[excited] "It becomes especially useful when you start choosing which profile fields should be reviewed and attach a form to capture structured detail such as goals, interests, or preferred content types."

[confident] "That makes personalisation much more credible. Regular profile reviews keep the data fresh, and the extra structured inputs make it easier to deliver genuinely relevant experiences."

## 4. Discussion notifications

[thoughtful] "Conversations stay healthier when people know they are being invited back into them. These notification updates make that much easier."

[informative] "When someone replies directly to your comment, you can now receive an alert in the platform and, if enabled, by email. The notification takes you straight back to the relevant thread."

"Contributors and moderators can also be notified when new activity appears in a discussion, whether that is a new top-level comment or a reply inside an existing thread. That makes it easier to catch momentum, questions, or conversations that need guidance."

[reassuring] "Both notification types can be grouped intelligently, so several replies in a short period do not have to become a flood of separate alerts."

[confident] "The result is a discussion space that feels more connected and much easier to stay engaged with."

## 5. Text and file responses

[thoughtful] "Collecting written or file-based work often meant sending people out to separate tools or awkward workarounds. These response types bring that activity into the learning flow itself."

[informative] "Authors can now add a text-response block with minimum and maximum character counts. Participants type directly in the step, submit when ready, and can cancel that submission up until review begins."

"File responses follow the same pattern, but for uploaded files. Authors can set minimum and maximum file counts and restrict which file types are allowed."

[excited] "Both response types also support a reflection mode. In that mode, the step completes automatically when someone submits, no formal marking is required, and the response can stay editable."

[confident] "That means written work and file submission can now sit naturally inside the learning experience, whether the goal is assessment or reflection."
